# Python-Code

Dieser Ordner enthält den ursprünglichen Python-Code, der als Referenz für die Portierung nach C# dient.

## Inhalt
Hier sollten die folgenden Python-Skripte abgelegt werden:
- Original-Python-Code für die BOM-Erzeugung
- Python-Skripte für Rhino-Integration
- Andere relevante Python-Dateien aus dem ursprünglichen Projekt

## Verwendung
Der hier gespeicherte Code sollte nicht direkt verwendet, sondern als Referenz für die C#-Implementierung betrachtet werden. Bei der Portierung sollten die Struktur und Logik des Python-Codes berücksichtigt werden, während gleichzeitig die C#-Konventionen und -Möglichkeiten genutzt werden.
