# Examplecode Ordner

Dieser Ordner enthält Referenzmaterial für die Entwicklung des RhinoPlugins.

## Unterordner

### python/
Enthält den ursprünglichen Python-Code, der als Referenz für die Portierung dient.

### csharp/
Enthält C#-Beispiele für die BOM-Erzeugung und Browserfenster-Integration sowie den portierten Code.

### rhino/
Enthält Codesnippets für die Rhino-Plugin-Entwicklung (z.B. Browserfenster öffnen).

## Verwendung
Diese Beispielcodes dienen als Ausgangspunkt oder Inspiration für die Entwicklung. Wenn auf diesen Code zurückgegriffen wird, sollte dies im `thoughtprocess`-Ordner dokumentiert werden, zusammen mit einer Erläuterung, wie der Code angepasst wurde.
