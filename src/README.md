# Source Code

Dieser Ordner enthält den Quellcode für das RhinoPlugin.

## Inhalt
Hier wird der Hauptcode des RhinoPlugins gespeichert, darunter:
- Implementierung des RhinoPlugins
- Code für die Erzeugung der Bill of Materials (BOM)
- Integration des Browserfensters
- Andere Komponenten des Plugins

## Struktur
Die Codestruktur sollte klar und nachvollziehbar sein, mit separaten Dateien für unterschiedliche Funktionalitäten. Die Entwicklung des Codes sollte im `thoughtprocess`-Ordner dokumentiert werden.
